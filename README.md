# tlm-log-reader
TLM log reader is an application that can read TLM log files (Spektrum RC telemetry log files) and show the telemetry data in table view or graph view.This webapp uses html and javascript and can run local in your own browser; no data is uploaded, nor downloaded. This is not an official Spektrum RC application;  This app is vibecoded with AI.<br/>

### - installation
Just download the tlm-log-reader.html file and open it with your browser. Everyting runs local, no internet needed.<br/>
Click on the "open TLM file" button, select your tlm log file and inspect your data.
<br/><br/>
###  - data decoding
This application should work with TLM files from any Spektrum DX, NX, IX transmitters. But I only tested with Spektrum NX8+
As for sensors I only have Spektrum AR6xx receiver and a Spektrum Avian 70A smart ESC. So I could only test the telemetry parsing with these sensors.
If you have troubles with decoding your TLM data send me your TLM files and I can try to fix this application and provide a new release/update.
